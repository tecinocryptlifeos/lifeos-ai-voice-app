# LOSAI Android Trusted Web Activity

This directory contains the Android wrapper configuration for the existing
LOSAI web application.

## Permanent identity

- Android package ID: `losia.htc.com`
- Trusted host: `lifeosai.pages.dev`
- Initial route: `/chat?source=android-twa`
- Web manifest: `https://lifeosai.pages.dev/manifest.webmanifest`
- Current Android release: `1.0.2` (`versionCode 3`)

## Interface boundary

The wrapper does not copy, replace or redesign the existing Chat or Voice
interface. It opens the current HTTPS LifeOSAI application served from
Cloudflare Pages as a Trusted Web Activity.

The Android wrapper must not redirect authentication, account/profile access,
Chat, Voice, or application navigation to the Render origin.

## Build boundary

The signed APK and Android App Bundle are generated by GitHub Actions.
Signing material remains in protected GitHub Actions secrets and build
artifacts are uploaded only as workflow artifacts.

The production build targets the Cloudflare Pages origin and the same
`/chat?source=android-twa` route used by the current web application.

No signing key or generated application package may be committed to Git.
